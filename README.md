# Amazon Sales Data–Exploratory Data Analysis (EDA)

This project performs exploratory data analysis on an Amazon sales dataset to understand pricing,discount patterns,and customer behavior across product categories.

## Tools Used
Python,Pandas,NumPy,Matplotlib

## Analysis Summary
- Cleaned and preprocessed real-world e-commerce data.
- Analyzed price and discount distributions.
- Performed category-wise analysis of discounted price,discount percentage,ratings and rating counts.
- Identified differences in pricing and promotional strategies across product categories.

## Key Insights
- Premium categories maintain higher prices while still receiving strong customer ratings.
- Discount levels vary significantly by category and are not directly correlated with price.
- Low-cost accessories receive aggressive discounts to drive higher sales volume.
